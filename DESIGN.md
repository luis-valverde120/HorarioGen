# HorarioGen design system

The Spanish interface uses a green, yellow, and white palette inspired by the supplied UPEC curriculum. The values are design choices. Official brand approval has not been established.

| Role | Value |
|---|---|
| Primary | `#106238` |
| Primary dark | `#084729` |
| Accent | `#FFCC29` |
| Background | `#F6F8F7` |
| Surface | `#FFFFFF` |
| Text | `#17251C` |
| Success | `#198754` |
| Warning | `#D97706` |
| Error | `#DC2626` |

Use the Inter and system sans-serif stack. Use four-pixel spacing increments, 8–12 px corners on interactive surfaces, a thin border, and subtle shadows where a surface needs separation. Use dark text on the yellow accent. Preserve visible focus rings and native keyboard behavior for buttons, inputs, selects, and disclosure controls.

Show named states alongside status colors. Timetable blocks retain the teacher color and show their actual lengths. Tutoring has a textual label and distinct border. Detailed and crowded schedules offer a readable agenda or horizontal scrolling. Keep transition effects brief and functional. Respect `prefers-reduced-motion` and avoid animating every poll result.
